## 交付（纯宿主侧，不碰网关代码/生产容器）

1. **直连源文件** `TEST/model-evaluator/sources.direct.json`：
   agnes（aimly key，all_free）+ xkiro（cc-xkiro key），今日探针同款（实测可出分）。
2. **有效行同步器**：主用 **`ops/dev-fleet/sync-admission.ps1`（原生 PowerShell）**，
   bash 版 `TEST/model-evaluator/scripts/sync-admission.sh` 保留作手动工具。
   判据与网关 internal/admission 同口径（`anthropic_ok ∧ verdict∈{PASS,FAIL,UNCERTAIN}
   ∧ dims 非空`），**与容器侧现存表合并去重**（单轮 429 不打掉历史证据，MergeAuto
   只增不减同款精神），原子写 `moretoken/docker/runtime/admitted.json`（30s mtime
   热加载，**零重启**）。
   - 为什么改 PS：bash 版在计划任务（wscript/hidden-run.vbs、无交互会话）上下文里
     两轮 `SYNC FAILED`，同命令交互式跑通（2026-10-08 实测）——无会话的 PATH 差异。
   - **PS 5.1 陷阱（已修）**：`Set-Content -Encoding UTF8` 写 BOM ⇒ 网关 Go
     json.Unmarshal 直接 reject ⇒ admission fail-open。改用
     `UTF8Encoding($false)`（无 BOM），python 直读验证。
3. **调度链** `ops/dev-fleet/admission-watch.cmd`：
   ① `model-evaluator.exe watch --sources sources.direct.json --limit 12 --delay 3s`
   ② `sync-admission.ps1` 把有效行推进容器 runtime 表。带日志
   `ops/dev-fleet/logs/AImlyForge-AdmissionSyncWatch.log`。
4. **注册脚本** `ops/dev-fleet/admission-watch-setup.ps1`（幂等 + -DryRun +
   -DisableLegacy）：注册 `AImlyForge-AdmissionSyncWatch`（每 30min，
   wscript.exe + hidden-run.vbs 隐藏包裹先例）。
   - 本机触发器怪癖（已实测 workaround）：`New-ScheduledTaskTrigger` 带
     `RepetitionDuration` 的任何有限值都超 XML duration schema（MaxValue、
     P36500D 全拒），**省略该参数 = 无限重复**；schtasks 从 PowerShell 调
     会吞嵌套引号（"missing required option sc"），只能用 CIM 注册。
