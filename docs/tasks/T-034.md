## 部署后新发现（→ 另立 T-035）

失败不是 404、也不是模型死了，而是 **403 `denied`**：

```
attempt: xkiro-anthropic kind=denied status=403 「请求被拒，与凭据无关；按模型级处理」
```

**xkiro 免费档的模型权限是"按账号（按 key）"的**——同一模型，部分 key 200、部分 403。
而 moretoken 依 2026-09-20 的结论把 403 当**模型级**（只换模型、**不换 key**）⇒ 抽到无权限的 key
就只能换模型（同样无权限）⇒ 耗尽 ⇒ 503。**这才是"不能循环找活大模型"的根。**
