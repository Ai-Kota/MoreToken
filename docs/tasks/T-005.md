## 目标
把 T-003 决策日志 + T-004 状态机事件经 NATS 总线发布，供 WorkBoard（外部仓 aimly-console）订阅。
纯后端、不内置 dashboard（GOALS 边界）；NATS 主题命名遵循 deploy/nats/NEURAL_BACKBONE.md §四。

## 三个交付
1. **internal/nats 发布层**（零依赖不破）：
   - 通过 `exec` 调本机 `nats.cli` 发布（不引外部 Go 依赖——纯标准库铁律）
   - NATS 不可用 / nats.cli 缺失时降级 no-op（纯后端可独立运行，NATS 是增强非依赖）
   - 两类主题：
     - `aimly.system.freetier.status`（status）：各池 Health + 当前 tier，定期/变化时
     - `aimly.system.freetier.event`（event）：state 层切换/回归/抖动事件，即时广播
2. **接线**：main 启动发布器；state.SetEventSink 同时写决策日志 + 发 NATS 事件
3. **WorkBoard 契约文档**（docs/workboard-contract.md）：
   - 主题名 + payload JSON schema（status / event 各一份）
   - 订阅示例（nats.cli sub / aimly-console 侧 TS 片段）
   - 密钥安全声明：payload 无 key 值、无请求体
