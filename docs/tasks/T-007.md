# T-007: 修 scripts/ ai-guard 存量测试失败（findSrcDir flake）

**允许修改文件**：scripts/cmd/ai-guard/main.go, scripts/cmd/ai-guard/main_test.go, docs/tasks/TASKS.md
**允许新增文件目录**：docs/tasks/

## 目标
`scripts/` 目录（ai-guard 工具链）存量测试在本机失败：
`TestFindSrcDirNone` 假设"Temp 祖先链无 go.mod"，但本机 `C:\Users\aimly\AppData\Local\Temp\go.mod`
存在残留 → findSrcDir 向上找到它 → 测试报 flake。
（另确认 TestFail/boom 是 verify-task 夹具的预期输出，非真失败。）

## 修复
- findSrcDir 加 stopAt 参数（向上搜索边界）：stopAt="" = 走到底（原语义，rebuild 用）；
  传边界 = 不越出该树。
- 测试不再依赖机器 Temp 状态：TestFindSrcDirNone 改 stopAt=自身；
  新增 TestFindSrcDirStopAtBounds 钉死"祖先有 go.mod 但越界则不返回"。

## 验收标准（DoD）
- [x] findSrcDir 加 stopAt 边界，生产调用点（rebuild）语义不变
- [x] TestFindSrcDirNone / TestFindSrcDirStopAtBounds 通过，不再依赖机器环境
- [x] `scripts/` 的 `go test ./...` 全绿
- [x] test-all.sh 整链（主项目 + ai-guard + lint + 冒烟）通过
