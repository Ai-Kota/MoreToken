# T-042: 付费档退出 auto:* 兜底链——日常流量只在免费池循环

> ⚠️ **已被取代（2026-10-12）** —— 用户改了定性。见 `CHANGELOG.md` `[Unreleased]` 首条
> 与 `MACHINE.md` §MoreToken 的 ⚠️ 块。**现行做法：把付费 key 并入免费池轮换**
> （`agnes` / `agnes-anthropic` 各 34 把中的 1 把 ≈ 3% 份额），池内**无 paid 档**；
> **不是**"付费档整体退出、仅供字面点名"。
> 本档下文描述的实现（独立 paid provider + `allow_paid_fallback` 闸）**代码里仍在、仍生效**，
> 但**生产配置已删掉两个 paid provider** ⇒ 那道闸**当前无作用对象**。读本档请以上层定性为准。
>
> ⚠️ 本次改动**未触及**下文"未核实"节里的问题：免费池中的 `agnes-3.0-flash` 是否扣付费
> 余额 —— 仍**未决**，已转 `docs/tasks/T-043.md`。

> 用户定性（2026-10-07，T-041 复盘时原话）：**"付费大模型兜底是个伪命题，
> 应该是免费大模型循环切换兜底才对。"** 此前 T-039 调研的"付费兜底"设计
> （router.go:134-149 层门控血账语境）与 T-041 实测观察到的
> "auto:coding 流量转 3.0-flash 付费档"，**均按本定性撤销**。
>
> 架构定案：**付费 key 只服务基建维护（显式点名直连）；日常任务 100% 免费池
> 内循环切换；免费全挂 ⇒ 503 + 等日额度重置（T-040 日账本配套）**。

## 交付

1. `config.Config` 加 `AllowPaidFallback *bool`（指针语义沿用 T-040 先例）：
   - **nil（未配置）= false（新政策：虚拟模型不进付费层）**——行为变化，
     升级说明必须写进 CHANGELOG；
   - 显式 `true` = 恢复旧行为（回滚闸，供 2026-09-20 型事故排查时临时开）。
2. `Router.candidates`（router.go:477）：虚拟模型（auto / auto:*）候选链
   **只取免费层**，除非 cfg.AllowPaidFallback==true。字面模型路由不受影响
   （`decliningCandidates` 路径不变——基建工具点名 `agnes-3.0-flash` 仍可直达付费）。
3. 测试：
   - 既有 `TestRoute_*付费兜底`（router_test.go:155-202 等）改为显式
     `AllowPaidFallback=true` 配置下运行（保旧语义回归）；
   - 新增：默认配置下 free 全 429/冷却 ⇒ 虚拟模型 **503 exhausted**（reason
     含 T-040 的 daily-quota banned 标注），**付费池 hit=0**；
   - 变异检验：闸失效 ⇒ 红。
4. docs：README 的"付费兜底"表述改为"付费点名直连（基建）+ 免费全挂 503 等日重置"；
   T-039 档补注"paid reasoning kind 保留但不再被 auto:* 消费（字面直连仍有效）"。

## 判据
- `go test ./...` 全绿；默认配置下实打 `auto:*`，构造 free 全冷却（单测即可，
  不烧真实额度）⇒ 付费 provider 0 命中；
- 字面模型点名付费档仍 200（宿主起网关，`model=agnes-3.0-flash` 直发 openai 路一发）。

## 验证（2026-10-07 实测输出）

1. **全仓测试**：`go test -count=1 ./...` 全 12 包绿；`go vet` 无输出。
2. **变异检验**：把 `candidates` 里的 `if virtualModel && !r.allowPaidFallback` 摘除（改 `if false &&`）⇒ `TestRouter_VirtualModel_NoPaidByDefault` **变红**（`应 503 耗尽，实际成功`），恢复后翻绿。测试真的在抓这道闸。
3. **上线实打**（`/tmp/mt-t042.exe` 起 8474，默认 config）：`auto:reasoning` / `auto:coding` 各一发全 200；`/decisions` 显示 **provider 只命中 `agnes`（免费层），付费 provider `agnes-paid-*` 命中 0**。
4. **字面点名付费档仍通**：`model=agnes-3.0-flash` 直发 openai 路 → 落到付费 provider（基建维护用途不缩水）。

**升级说明（写进 CHANGELOG）**：默认行为变化——`auto:*` 虚拟模型不再 fallback 进付费层；免费全挂返回 503（含 T-040 的 daily-quota 标注），需显式 `allow_paid_fallback: true` 才恢复"免费挂转付费"旧行为。

## 未核实（诚实标注）
- **免费池里的 `agnes-3.0-flash` 模型**：它被 harvest（`config/models.auto.json`）收进了**免费** agnes provider 的模型清单，`auto:*` 可合法路由到它（免费 provider 内的模型轮换，不经付费层）。但 3.0 本身是"付费维护"定位的模型，**从免费 key 出它是否真按免费计费，我没有数据证实**（pro 系曾报 `remaining: ＄0.00` 是另一回事）——这不属于 T-042（T-042 只管付费 provider 出链），单列给用户定夺。
- 未做"真实全 429 风暴"生产复现（会烧额度）；免费 429 全冷状态由单测 `TestRouter_VirtualModel_NoPaidByDefault` 覆盖。
