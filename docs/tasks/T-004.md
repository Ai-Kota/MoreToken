# T-004: 免费/付费确定性状态机（差异化核心）

**允许修改文件**：internal/**, main.go, docs/**
**允许新增文件目录**：internal/

## 目标
把 T-002 的"被动回归"（池退避到期自动切回）升级为 ADR-003 四支柱之"自动回归（确定性）"：
**后台健康探测 + 免费恢复健康 ≥T 分钟 → 确定性切回 + 防抖**。这是相对 FreeLLMAPI 的存在意义
（GOALS.md：FreeLLMAPI 评分池不保证省钱最大化，GTG 用显式状态机保证）。

状态机（ARCHITECTURE.md §五）：
```
FREE（免费层）──全部免费不可用──→ PAID（付费链）
    ↑                                 │
    └──免费恢复健康 ≥T 分钟（确定性回归）─┘
```

## 三个要补的机制（T-002 已做的是"被动到期回归"，本任务补"主动确定性判定"）
1. **后台健康探测**：停在付费时，周期探测免费层（主动发探测请求，不等被动到期）
2. **I4 确定性回归**：免费层"健康"需连续探测成功 ≥T 分钟才切回（宁慢勿抖，T 可注入）
3. **I5 防抖**：免费恢复 <T 分钟再次全挂 → 健康计时清零，不触发回归（抖动事件后 free 决策数=0）

## 注意
- 状态机不碰路由层：它产出"当前该在哪层 + 回归事件"，router 按层选择（T-002 已支持 tier 优先）
- 探测请求用最小 body（成本近 0），失败 429 不惩罚探测本身（探测是可重放的安全操作）
- 纯标准库零依赖不变；T 默认 3 分钟（ADR-003 "默认 3-5"），测试用 fake clock 注入秒级
