# T-048: T-043 配套——生产排除名单 + tier 观测回归修复

> 状态：**执行中（2026-10-25）**
> 来源：2026-10-25 容器体检。两项均需动 T-043 范围之外的文件：
> ① `config/config.json` 写入 `exclude_models`（T-043 的白名单只有代码与生成物）；
> ② `internal/state/state.go` 的观测档位卡 paid。

## 背景（已核实证据）

- 运行中容器配置里 `agnes-3.0-flash` 仍挂在 `agnes` / `agnes-anthropic` 两个免费池，
  与 T-043 用户定案冲突。T-043 代码侧（排除名单）已由本会话实现。
- 实时 NATS status：`tier=paid`，而所有池 `backed_off=false, cooling=0`。
  `state.TickOnce` 在无隔离池时直接返回，`ProbeFree` 永不执行 ⇒ 档位无法回归 free。

## 改动

1. `config/config.json` 增加：
   ```json
   "exclude_models": ["agnes-3.0-flash"]
   ```
2. `internal/state/state.go`：`TickOnce` 在 `tier==TierPaid` 时也继续探活
   （有隔离池时仍探，两条件取并集），让 `free-healthy>=T` 回归分支可达。
