# T-043: 3.0-flash 剔出免费池（防 harvest 复发）

> 来源：T-041 勘误 + T-042「未核实」。3.0-flash 被 harvest 收进**免费** agnes
> provider（config/models.auto.json），auto:* 可合法落到它；但 3.0 定位"付费维护"。

**定案（2026-10-08 用户拍板）：不用 3.0-flash 走免费池**——走保守路线 b：
免费池不押它（计费口径未核实，不烧免费 key 的付费余额）。

## 3.0-flash 出现的全部位置（动手前盘清，避免只堵一处）

| 位置 | 现状 | 处置 |
|---|---|---|
| ① 免费池 | `config/models.auto.json` 里 `agnes` / `agnes-anthropic`（+付费 provider）的 `verified` 共 4 处 | **剔出**（本任务核心） |
| ② 付费 provider | `config.json` 手写 `agnes-paid-anthropic` / `agnes-paid-openai`（T-039 加过 reasoning kind） | **保留**（基建字面点名直连通道；T-042 后 auto:* 已不碰付费） |
| ③ 准入表 | `docker/runtime/admitted.json` 有 3.0-flash 行 | `ApplyAdmission` 会把它**又加回免费池**——需一并处理 |

## 复发机制（必须先堵死）

`main.go -harvest`（dev-fleet 每 5min 拉起、TTL 20h 天级真跑）会**重新实测并重新纳新**：
`catalog.Harvester.Run` 对 `Known`（config 里已有 id）跳过实测，但**继承旧清单**
（`main.go:514-527` `prev` 累积并入）——所以单纯删 `models.auto.json` 下一轮会被
`prev` 继承**再加回来**。正确修法：加一个 **config 层排除名单**（如
`config.Config.ExcludeModels []string`），让 harvest 的继承/纳新都跳过它、
`ApplyAdmission` 也据此跳过（防 ③ 回流）。
