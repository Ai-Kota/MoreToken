# ADR-003: 定位变更 — 从"免费聚合替代方案"改为"免费优先的会话保持型路由网关"

## 状态

已接受（重新定位，supersede ADR-001 的"Go 重写 OmniRoute auto 免费模式"框架）

## 日期

2026-08-23

## 上下文

### 参考现实（已对本机 OmniRoute auto 三层核实：源码 + 运行实例 API + 活动 DB）

本机 OmniRoute auto 的真实机制：

1. **它是"加权评分池"，不是"层级状态机"**
   - 候选池 = 所有活跃连接，按 category（coding/reasoning…）与 tier（free/pro）过滤
   - `auto/coding:free` = 只留免费模型，**fail-open**：免费池为空时回退到全部 provider（含付费）——这是它唯一兜底，且是"全有或全无"，不是层级链
   - 12 因子加权评分（health 0.20 / quota 0.15 / costInv 0.15 / latency / taskFit / tier…），无确定性"免费→付费→回归免费"逻辑
2. **会话不掉线（用户最认可能力）的真实来源 = LKGP 会话粘性 + 恒定端点**
   - 上一次成功 provider 优先；挂掉后评分换下一个；端点和会话永远不变
3. **自愈机制**：熔断器（OPEN/HALF_OPEN/CLOSED）、评分<0.2 排除 5min→30min 退避、probe 请求
4. **实际运行状态（`~/.omniroute/storage.sqlite`，2026-08-23）**：
   - 517 条免费目录仅是**参考目录**（灰色 provider 居多，tos=avoid/caution），实际连接只有 3 个 provider（siliconflow active / glm-cn / nvidia error）
   - 现有唯一持久 combo：`coding-quality-first` = glm-5.2 主力 + opencode 免费备用
   - **OmniRoute 的不稳定主要来自 517 条灰色池 + bandit 随机探索 + incident mode 的复杂状态机**

### 用户真实目标

- **降低开发成本**——现在与以后都是唯一目标
- 免费模型为原则主力；付费模型仅是"救生艇"：免费全部不可用时顶上
- **免费恢复后必须确定性切回免费**（用户明确要求，非评分自然偏回）

## 决策

本项目定位为**免费优先的会话保持型路由网关**，四个支柱：

1. **无缝（继承）**：LKGP 会话粘性 + 熔断自愈 + 请求级重试 + 恒定端点——会话永不掉线
2. **免费优先（确定性）**：只要有任一免费模型健康，就走免费层；评分仅在免费层内部选"当下最健康"
3. **付费兜底（确定性）**：全部免费不可用 → 显式付费链（如 DeepSeek），不混池评分
4. **自动回归（确定性，增量）**：后台探测到免费层恢复健康 ≥ T 分钟（默认 3-5，防抖）→ 切回免费

### 状态机（核心）

```
FREE（免费层）──全部免费不可用──→ PAID（付费链）
    ↑                                 │
    └──免费恢复健康 ≥T 分钟（确定性回归）─┘
```

### 关键设计规则

- **层级优先是绝对的**：免费与付费绝不混池评分（否则评分高的付费模型会抢免费名额，违背省钱目标）
- **重试安全边界**：仅在"响应字节发出前"重试（连接错误 / 429 / 5xx / 超时）；流已开始不透明重放，按显式策略处理（防止 tool-call 重复执行）
- **请求级重试后同请求重放到链上下一个模型**，实现当前轮的"无感"
- **防抖优先于灵敏**：探测与回归阈值宁慢勿抖（沿用 Jiutian"3s 超时误伤正常响应"的教训）

### 范围不包含（砍掉）

- ❌ 免费目录聚合管道（不再爬 517 条灰色目录；免费 provider 直接在 config 中手写，只留稳定几个）
- ❌ bandit 随机探索 / incident mode / 复杂评分池（OmniRoute 不稳定之源）
- ❌ Dashboard、多用户、规则引擎、预算账本、NATS 遥测（当前不为省钱目标服务）
- ❌ Claude/Google OAuth 的 404 占位登录按钮（删除或延后）

### 继承的现有代码

- ✅ `router/scoring.go`：改为"免费层内选最优"（保留 Available/TOS/ModelSize 语义）
- ✅ `router/fallback.go`：改造为分层链重试策略（保留指数退避/冷却）
- ✅ `oauth/`：GitHub Copilot 降级为"免费兜底 provider 之一"（不为主角）

## 理由

- **成本优先**：免费层绝对优先 + 付费仅救生艇 + 确定性回归，全链路只服务省钱
- **稳定**：砍掉灰色池与复杂状态机，用少量手选稳定 provider，直接解决"OmniRoute 太不稳定"的痛
- **可维护/可拥有**：单二进制、纯标准库、逻辑显式（状态机 + 层级规则），符合"高可维护、高可定制、完全属于我"

## 影响

- **正面**：会话不掉线（继承）；省钱最大化（免费优先 + 确定性回归）；稳定性大幅提升（小池 + 无随机探索）；逻辑可审计（决策来自显式规则而非黑盒评分）
- **负面**：需要实现 Anthropic 协议端点（接 Claude Code）——这是主要工程投入；免费层可用时也必然受免费 provider 自身稳定性上限约束

## 待定（进入实现前需定）

1. **协议优先级**：Claude Code 走 Anthropic Messages API（`/v1/messages`，含流式事件 + tool_use 保真翻译）→ 建议 Phase 1 先做；OpenAI `/v1/chat/completions` 现有端点保留
2. **免费链配置**：具体保留哪几个稳定免费 provider（如 siliconflow / glm-cn / Copilot OAuth），手写进 config
3. **付费链配置**：DeepSeek 等作为救生艇的顺序

## 替代方案

| 方案 | 优点 | 缺点 | 结论 |
|------|------|------|------|
| 维持 ADR-001（免费聚合替代品） | 对齐 OmniRoute | 免费池缩小 + 灰色池不稳定 | 放弃 |
| 直接充值单一付费（DeepSeek） | 最简单 | 失去免费优先省钱、失去多模型韧性、不满足"完全属于我" | 放弃 |
| 自建会话保持型网关（本 ADR） | 省钱 + 稳定 + 可拥有 + 会话不掉 | 需自维护协议翻译层 | **采纳** |
