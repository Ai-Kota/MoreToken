# 事故集（incidents）—— 按时间读的完整案子

> 这个目录收**每一起真实事故的完整案子**：现场 → 定位 → 根因 → 修法 → 验证 → 教训。
> 一次事故一份文件，只增不改（后补的认知写进新的"追记"小节，不重写历史）。

## 与 `TROUBLESHOOTING.md` 的分工

两份文档**不是重复**，是两种读法：

| | `TROUBLESHOOTING.md` | `docs/incidents/` |
|---|---|---|
| 读法 | **按症状查**（grep 错误原文） | **按时间读**（从头看一个案子的完整推理） |
| 回答 | "这个报错是什么、先看哪" | "当时到底发生了什么、为什么、怎么想明白的" |
| 形态 | 速查表 + 分节，可随时插新条目 | 一份案子一个文件，叙述连贯 |
| 更新 | 结论变化时**改口径**（旧的划掉、注明为何作废） | **不重写**——历史是历史 |

出事时先查 `TROUBLESHOOTING.md`；想知道"这类问题我们踩过几次、当时的判断对不对"，读这里。

## 这个目录为什么存在

**修一层会露一层。** 2026-09-20 那起三分钟的事故，最后牵出四条独立缺陷 + 一批原则。
把它们摊在四个任务档里，下次没人能拼回全貌；拼不回全貌，就会重复踩同一个坑。

更实际的一条：**这类事故的"难"从来不在修，在发现和相信**。
本仓库有记录的事故里，修复都不难，难的是当时怎么从三个断掉的观测链里把真相抠出来——
那部分方法比结论耐用，值得逐字留下来。

## 写法约定

- **文件名**：`YYYY-MM-DD-<症状-slug>.md`（如 `2026-09-20-autoreasoning-503.md`）
- **必含**：症状 / 现场判据 / 定位路径 / 根因 / 修法 / **验证** / 教训 / 仍未做的
- **判据优先**：每条"根因"都要附实测证据或可复现的复现；只有推断的地方**显式标【未核实】**
  （见 `E:/MASTER/真言.md`：没有判据的结论不算结论）
- **留上游原文**：错误字符串**原样保留**，可直接 grep
- **写清"当时不知道什么"**：只知道结论的事后叙述会骗人，下一个人照着它做会踩空

## 常用判据速查（从案子里抽出来的）

| 判据 | 一句话 |
|---|---|
| 兜底不可低于主力 | fallback 的候选集必须 ⊇ primary 的。违反它，触发兜底的唯一效果是减少可用性 |
| 吸收即销毁证据 | 系统越擅长吸收失败就越不透明 ⇒ 失败必须在**带外**留一等公民记录 |
| 假绿比空白更贵 | 空白让人去查，假绿让人基于错误前提收工 |
| 静态性质才能穷举检查 | 运行时状态只许改候选的**顺序与跳过**，不许改**存在** |
| 变异检验 | 新测试必须对着旧代码跑一遍并失败，且症状与现场逐字一致 |
| 先查实再设计 | 动手前先验前提（"纳进来的模型用得上吗"救回了一整个交付） |
| 窄在措辞，不窄在结构 | 判据"宁可窄"是对**措辞**说的；结构化字段（`error.type`）才是可靠判据——靠词表认形状，上游换个说法就全瞎 |
| 结论要带"对谁成立" | "403 与凭据无关"只对某些上游成立，被当成普适规律写进路由后白扔半个 key 池 |
| "不惩罚"≠"不重试" | 为防长禁 key 而删动作时，别把"换一把再试"一起删掉——两件事要分开 |
| 集合要有人维护 | 手写白名单 + 只增不减 = 单调腐化。易腐供给必须有**淘汰/复核**环 |
| 静态断言 ≠ 活供给 | 配置声明的覆盖 ≠ 上游此刻能服务的。前者烂成墓地也照样绿 |
